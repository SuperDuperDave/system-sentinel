# Contributing to System Sentinel

Thank you for your interest in contributing to System Sentinel!

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a feature branch (`git checkout -b feature/your-feature`)
4. Make your changes
5. Commit (`git commit -m 'Add your feature'`)
6. Push to the branch (`git push origin feature/your-feature`)
7. Open a Pull Request

## Development Setup

See the [README](README.md) for setup instructions.

## Code Style

- **Python (backend)**: Follow PEP 8. Use type hints where practical.
- **TypeScript (frontend)**: Follow the existing ESLint configuration.

## Reporting Issues

- Use GitHub Issues to report bugs
- Include your OS version, Python version, and Node.js version
- Include relevant error logs or WHEA data (sanitized of personal info)

## Pull Requests

- Keep PRs focused on a single change
- Include a description of what changed and why
- Update documentation if needed
