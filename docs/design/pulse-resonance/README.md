# System Pulse — Resonance

An interactive design study of a tactile signal instrument. Open `index.html` directly in a browser; no build or service is needed. It adds no production route or release rename.

The form language uses offset signal reeds in the mark, recessed controls, raised reading surfaces, small source objects and a circular instrument that changes with the selected reading. Pale mineral and graphite appearances share this grammar. This is exploratory design, not an accepted identity. The UI uses CSS material effects and SVG data marks; no generated hero image is used in this study.

Try taking an illustrative pulse, selecting a source, opening the incident, inspecting records and preparing a report preview. The Example selector exposes empty matches, denied access, unknown retained reach and lost collector contact. Appearance cycles system, dark and light. All controls are local; no machine is queried and no report is sent. Google Fonts is optional, with system fallbacks.

## Evidence contract

Every quantitative display comes from the synthetic `sample` object or a named derivation. The sample is collected from 09:59 to 10:00 UTC on 2026-10-01, and asks about the preceding 24 hours. This is a fixed illustrative observation, not the current PC state.

- One composed stop is supported by Event 6008 / record 1201, Event 41 / record 1200 and Event 1001 / record 1202. Three supporting rows do not become three incidents.
- The stop estimate is 09:42 UTC. The next-start filing occurs after 09:46 UTC. The difference is not claimed as outage duration. The recorded code is 0x124, or decimal 292; it does not establish the failing component or root cause.
- In the restart reading, the instrument's 24 ticks represent hours in the selected period. The top is its end, labeled 10:00; the incident mark is positioned from the recorded stop estimate. Its center is a count of composed incidents, never a health score.
- The volume contains 512 GiB total and 132 GiB free. Used capacity is derived as 380 GiB. Both the circular capacity mark and the linear bar depict that ratio; they do not establish growth or safe cleanup.
- Denied hardware-error access has unknown content (`rows: null`). The empty example returns no matching rows and does not establish absence of a fault. The partial example additionally declares unknown retained reach. The shape used for denied access is an outcome sign, not missing time quantified on a clock.
- Unavailable collector contact retains the same saved sample. Taking a pulse refuses to create a fresh reading and does not infer why contact was lost. Changing examples during the brief demonstration cancels that demonstration.
- The report retains date, UTC, selection scope, references and limits. It is a preview. Its factual copy is deterministic sample composition, not a diagnosis or assistant interpretation.

No actual telemetry, baseline, prediction, notification rule, process history or repair is added. Native controls and focus handoff are present, but user comprehension and assistive-technology behavior still need evaluation. Browser checks establish only behavior with synthetic input; they cannot establish Windows collector behavior, installer behavior, usefulness on a real incident or acceptance of this style.
